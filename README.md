## ✨ Hakkında

**Dönüştür**, görsel ve PDF dosyalarını tarayıcı üzerinden hızlıca dönüştürüp düzenlemeni sağlayan bir web uygulaması. Kayıt gerektirmez, dosyaların saklanmaz — her şey anlık işlenir.

## 🚀 Özellikler

| Araç | Açıklama |
|------|----------|
| 🖼️ **Görsel Dönüştürücü** | JPG, PNG, WebP, AVIF, GIF, TIFF arası dönüşüm (SVG → PNG/JPG dahil) |
| 📄 **Görsel → PDF** | Birden fazla görseli tek PDF'te birleştir |
| 🖨️ **PDF → Görsel** | PDF sayfalarını PNG olarak dışa aktar (çok sayfa → ZIP) |
| 🔗 **PDF Birleştir** | Birden fazla PDF'i tek dosyada topla |
| ✂️ **PDF Sayfa Seç / Sil** | İstediğin sayfaları tut veya çıkar |

## 🛠️ Teknolojiler

- **Next.js** (App Router) + **TypeScript**
- **Tailwind CSS** — arayüz
- **sharp** — görsel işleme
- **pdf-lib** & **pdf-to-img** — PDF işlemleri
- **Vercel** — deploy

## 💻 Kurulum

```bash
git clone https://github.com/ademucar/donusturucu-site.git
cd donusturucu-site
npm install
npm run dev
```

Ardından tarayıcıda `http://localhost:3000` adresini aç.
